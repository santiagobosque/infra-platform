# infra-platform
terraform - Infrastructure as a code
ansible - VM configuration
k8s - helm chats
argocd - gitops
monitoring - prometheus, grafana, loki

1. This is infrastrucure project for hosting applications. Provides dev, stage and prod environments. Auto deployment and monitoring.
2. How to start? Learn README.ME in each directory starting from terraform dir.
3. Architecture - Terraform IaaC, Ansible for VM configuration, k8s for cluster orchestration, argocd for gitops and monitoring via prometheus, grafana, loki
4. Requirements installed terraform and ansible, kubectl, helm
